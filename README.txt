CARA MAIN : Buka file index.html di browser Chrome/Firefox
            Tidak perlu install apapun!

KONTROL   : Arrow Keys(Up & Down)(Untuk player 2) / WS — bergerak(Untuk player 1) 
            R — restart
            enter/space — mulai game vs ai
            T — mulai game vs player (Multiplayer) 
            P — pause/lanjutkan
            shift — slow-mo 

DESKRIPSI :
  Pong adalah game yang berfokus dalam permainan
  memukul bola dengan paddle bertujuan untuk 
  memasukkan bola ke area lawan untuk mencetak poin.
  Player diwajibkan bertahan dari serangan lawan 
  sampai skor mencapai 5 poin untuk meraih kemenangan.

TEKNOLOGI : HTML5 Canvas + JavaScript
            Tidak ada library eksternal
